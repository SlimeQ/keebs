# English Word Assets

`english-common-words.txt` is derived from `5000-more-common.txt` in
Michael Wehar's `Public-Domain-Word-Lists` repository.

Source:
https://github.com/MichaelWehar/Public-Domain-Word-Lists

The repository README states that `5000-more-common.txt` was generated by
Michael Wehar and released into the public domain.

Keebs expands this seed list at runtime with dictionary-confirmed inflections
and a small maintained backfill of common app/typing terms. That keeps the
ranked common vocabulary broad enough for prediction without promoting the
entire dictionary into the high-confidence language model.

`english-dictionary-words.txt` is derived from `words_alpha.txt` in the
`dwyl/english-words` repository.

Source:
https://github.com/dwyl/english-words

The repository is distributed under the Unlicense.

`pretrain-corpus.txt` is a bundled first-run training corpus maintained in this
repository. It seeds common contractions, starter phrases, and next-word pairs
without reading user text or requiring network access.
